## Special Considerations for 250 Guests

### Capacity Verification
All researched venues were confirmed to accommodate 250 guests for both ceremony and reception. Some notes:

- **Ceremony + Reception:** Most venues can host 250 seated for dinner
- **Cocktail Reception:** Several venues accommodate 300+ for cocktail-style events
- **Space Flexibility:** Resort venues offer multiple backup locations for weather
- **Outdoor Ceremonies:** Most have indoor backup for April showers

### Logistical Considerations
- **Guest Accommodations:** Resort venues simplify lodging (JW Marriott Marco Island has 809 rooms)
- **Transportation:** Consider shuttle services for destination weddings
- **Weather Backup:** Critical for April outdoor ceremonies
- **Vendor Access:** Check if venues have preferred/required vendor lists
- **Setup Time:** Larger guest counts need adequate setup/breakdown time
