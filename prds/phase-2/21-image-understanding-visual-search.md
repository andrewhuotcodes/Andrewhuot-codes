# PRD-021: Image Understanding + Visual Search

**Phase:** 2 — "Make It Intelligent" | **Priority:** P1 | **Quarter:** Q4 2026
**Pillar:** Multimodal | **Status:** Draft
**Author:** Chat SDK Product Lead | **Last Updated:** February 2026

---

## Introduction

Users increasingly want to show, not tell. "I want shoes like these" (with a photo) is more natural than describing the exact style, color, and heel height. Gemini's multimodal capabilities can analyze images natively, but the Chat SDK has no mechanism for users to share images or for agents to process them.

This feature adds image input to the chat (camera capture and file upload) and connects it to Gemini's vision capabilities for product identification, visual search, and contextual understanding.

---

## What Are We Building

### Image Input Methods

1. **File upload:** Button in the input bar that opens the system file picker
2. **Camera capture:** Direct camera access via `getUserMedia()` for real-time photo capture (mobile-optimized)
3. **Paste from clipboard:** Users can Ctrl+V / Cmd+V images into the chat input
4. **Drag and drop:** Drag images from the desktop into the chat widget

### Visual Search Widget

When a user shares a product photo, the agent can respond with visually similar products:

```
User: [Photo of blue sneakers]
User: "Find me these shoes"

Agent: "I found these Nike Air Max 90 in Blue/White.
        Here are similar options in your size:"

[Product Carousel: 4 visually similar shoes with prices]
```

### Image in Messages

Images appear as inline thumbnails in the message history. Tapping opens a lightbox view. Images include alt text (generated by the agent) for accessibility.

## What Does Success Look Like

### Metrics

| Metric | Target | Measurement Method |
|--------|--------|--------------------|
| Image message adoption | >10% of sessions include at least 1 image | Message analytics |
| Visual search conversion | >25% of visual search results lead to cart adds | Commerce funnel |
| Image processing latency | <3 seconds from upload to agent response | Timestamp analysis |
| Supported image formats | JPEG, PNG, WebP, HEIC | Feature validation |

### Success Criteria

1. A user photographs a product, the agent identifies it, and shows similar products — all within the chat thread in <5 seconds.
2. Images are compressed client-side before upload to stay under bandwidth limits.
3. Camera capture works on iOS Safari and Android Chrome.

## Critical User Journeys

### CUJ 1: Visual Product Search
**Actor:** User who sees a product in the real world
**Goal:** Find and buy a similar product online

1. User taps camera icon in chat input
2. Camera opens (mobile) → user photographs a pair of boots
3. Image appears in chat: thumbnail with upload progress
4. Agent processes image: "I see a pair of brown leather Chelsea boots. Searching for similar styles..."
5. Product carousel renders with 6 matching boots from the Shopping Graph
6. User taps one → product details → adds to cart

### CUJ 2: Screenshot-Based Support
**Actor:** User encountering an error on a merchant's site
**Goal:** Get help by sharing a screenshot

1. User takes a screenshot of an error page
2. Pastes (Ctrl+V) into the chat input
3. Agent analyzes the screenshot: "I can see you're getting a 'payment declined' error. Let me help troubleshoot."
4. Agent provides specific guidance based on the error visible in the screenshot

## Open Questions

1. **Image moderation.** Users could share inappropriate images. Should we add client-side moderation? Recommend: backend moderation via Cloud Vision SafeSearch before the agent processes the image.

2. **Multiple images per message.** Should users be able to attach multiple photos? Recommend: yes, up to 4 images per message (aligned with other chat platforms).

3. **Video input.** Should Phase 2 include short video capture? Recommend: defer to Phase 3. Image is sufficient for visual search.
